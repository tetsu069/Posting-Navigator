# Posting Navigator

## v1.8.3 折り返し・境界表示・通行状態表示
- 短いOSM分割片を「短い道」と誤認して道路途中で折り返す挙動を抑制。即時折返しは袋小路を優先し、必要な側切替は実際の曲がり角・交差点側へ寄せる。
- 境界外救済道路が道路途中の折返しを誘発しにくい評価へ変更。
- 選択エリア境界線を太く・濃く表示。
- 現場モードで未配布=赤、片道配布済み=青、往復/両面完了=緑として表示。

## v1.8.3 境界道路は内側1面だけ配布

- 町丁目の境界線に沿う道路は、対象エリア側の住居だけを配布対象として扱います。
- 境界道路は原則1回だけ通過し、対象エリア側が進行方向の左になる向きを自動選択します。
- 境界道路を「左右2面」とみなして強制往復する処理を廃止しました。
- 内部道路は従来どおり左右2面を別タスクとして処理します。
- 小区画を完了してから次の小区画へ移るルールは維持します。
- 境界道路を含むため、理論上の必要配布距離は一律2.00倍ではなく、境界道路長を1回分差し引いて計算します。


## v1.6.0 左右配布タスク方式

道路そのものを「往復必須」と考えるのではなく、道路の左右を別々の配布タスクとして管理します。進行方向の左側を処理し、通常交差点では同一道路を即座に逆戻りせず、同じ小区画の別道路を回ってから反対側タスクへ自然に戻ります。袋小路だけは奥で折り返して反対側を処理します。小区画完結ルールは維持し、区画内の左右タスクが完了するまで次区画へ移りません。


## v1.6.0 左側配布モード
- 歩行中は常に左側の住居へ配布する前提。
- 各配布対象道路を正方向1回＋逆方向1回、必ず両方向に通ります。
- 小区画を完全に処理してから、最寄りの次小区画へ実道路で移動します。
- 小区画内の理論下限は対象道路長の2倍。3回目以降の再通行は区画間移動で必要な場合だけに抑えます。
 v1.6.0 — 非Euler型ルーティング

v1.6.0 は巡回エンジンを根本変更しました。

- Chinese Postman / Euler化を通常の巡回生成から外しました。
- 未巡回の配布対象道路を直接1回ずつ消化します。
- 同じ道路を再利用するのは、現在地から次の未巡回道路へ実道路上で移動する必要がある場合だけです。
- 再利用済み道路、とくに primary / secondary / tertiary の再利用には非常に大きな移動コストを設定します。
- 未巡回道路ゼロ保証、境界道路保持、道路外直線禁止は維持します。
- 格子/街区の sweep 情報と袋小路のその場処理を維持します。

従来のEuler補完関数は互換テスト用に残っていますが、generate_route() の通常経路では使用しません。

## v1.8.3 ハイブリッド配布ルーティング

道路の片側を配布単位とし、境界道路はエリア側のみ、極細路地は1回で両側、袋小路・短路は折返し可、通常/長路/大通りは反対側の即時折返しを避けて小区画周回後に処理する。小区画完結を最優先とする。
