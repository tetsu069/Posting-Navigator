# Posting Navigator v1.4.0 — 非Euler型ルーティング

v1.4.0 は巡回エンジンを根本変更しました。

- Chinese Postman / Euler化を通常の巡回生成から外しました。
- 未巡回の配布対象道路を直接1回ずつ消化します。
- 同じ道路を再利用するのは、現在地から次の未巡回道路へ実道路上で移動する必要がある場合だけです。
- 再利用済み道路、とくに primary / secondary / tertiary の再利用には非常に大きな移動コストを設定します。
- 未巡回道路ゼロ保証、境界道路保持、道路外直線禁止は維持します。
- 格子/街区の sweep 情報と袋小路のその場処理を維持します。

従来のEuler補完関数は互換テスト用に残っていますが、generate_route() の通常経路では使用しません。
