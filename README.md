# Posting Navigator v1.2.1 — 蛇行・袋小路即処理 強化版

1町丁目=1ルートのまま、現場で「何度も同じ所へ戻る」「行き止まりを通り過ぎて後から戻る」動きを減らした版です。

## v1.2.1 の主な変更

- **真の行き止まりをその交差点へ到達した時点で優先処理**します。幹道路を通り過ぎて後から戻る順序を強く抑制します。
- Euler巡回の辺選択をFleury寄りにし、**他の選択肢がある間はbridgeを使わない**ことで、道路途中で自分を袋状に閉じ込めて即折り返す挙動を抑えます。
- 格子状道路では、街路主軸を推定し、行ごとに方向を反転する**蛇行（serpentine / lawnmower）順序**をより強く優先します。
- GOAL候補を最大24点まで比較し、巡回候補探索も増やして、**途中Uターン・長距離の戻り・完了済み区画への再訪が少ない候補**を選びます。
- 複数の道路成分はv1.1.9同様、近い成分から順番に完全処理します。接続不能成分間に道路外の偽直線は描きません。
- 町丁目外道路、公園内の不要園路は配布対象にしない方針を維持します。

## 巡回の優先順位

1. 今いる交差点の短い行き止まりを処理
2. 今いる近接ブロックを完了
3. 格子状エリアは同じ列・行を端まで進んで隣列へ蛇行
4. 同じ道路の即時折り返しを避ける
5. 完了済み区画へ戻らない
6. その条件の中で重複距離を短くする

## テスト

```bash
pytest -q
node --check docs/app.js
```

現行テストでは、格子状道路での非袋小路即時Uターン0件、袋小路の即時処理、全対象道路カバーを確認しています。
