# Posting Navigator v1.1.3 — 現場優先・取り残し防止版

1町丁目を1本の巡回ルートとして生成するポスティングナビです。

## v1.1.3 の主な変更

- 住宅街の生活道路だけを「配布必須」として扱い、太い幹線道路は必要な移動時だけ使用。
- 公園内の footway/path/service は配布必須から外し、どうしても接続に必要な時だけ使用。
- 境界線のすぐ外側に中心線がある生活道路は、境界に平行かつ4m以内の場合だけ境界道路として救済。
- 境界から外向きに伸びる枝道は巡回対象にしない。
- 行き止まりは幹道路を通っている時にその場で処理する方針を強化。
- 真の袋小路以外での即時折り返しを強く禁止。
- GOAL候補を複数試し、道路途中のUターンが最も少ない巡回順を選択。
- 太い道路・公園・駐車場通路は全線を何度も往復せず、必要な connector としてだけ利用。
- transfer 区間も必ず実OSM道路geometry上を通り、道路外の直線を作らない。

## ルート評価の優先順位

1. 道路途中の不要な折り返しをなくす
2. 今いる住宅ブロック・枝道をその場で完了する
3. 取り残した道路へ後から戻る動きを減らす
4. 公園・幹線道路など配布価値の低い道路を必要以上に通らない
5. その条件の中で重複距離を小さくする
