# Posting Navigator v1.2.5 — 境界小枝除去・境界道路連続カバー版

v1.2.3をベースに、町丁目境界に沿う実道路が巡回対象から抜ける問題を修正しました。

## v1.2.5 の追加修正
- 境界をまたいで外へ続く道路のうち、町丁目内に55m以下だけ残る短い切れ端は配布必須から除外します。道路自体は移動用として保持するため、必要な接続は壊しません。
- 境界道路救済を5mから7.5mへ拡張。ただし境界と局所的に平行な区間だけを抽出するため、外向き枝道は救済しません。
- 1本のOSM wayが途中で曲がっていても、境界に沿う部分だけを局所判定して救済するため、長い境界道路の一部抜けを減らします。

## v1.2.5 の変更

- 町丁目内の道路は従来どおり厳密に対象化。
- 行政境界が道路端に置かれ、OSM道路中心線が数mだけ外側になる場合を救済。
- 救済対象は境界5m以内かつ境界とほぼ平行な生活道路系のみ。
- 境界から外向きに伸びる枝道は救済しない。
- 境界から離れた外側道路は巡回対象にしない。
- 救済した境界道路は `boundary_near=true` かつ配布対象として巡回する。
- v1.2.3 の無駄な即時往復除去・公園内不要路抑制などは維持。

## 狙い

地図上で「青い町丁目境界だけ表示され、実際の境界道路に巡回線がない」箇所を減らし、実在する境界道路を漏れなく配布対象に含めます。一方で、エリア外へ向かって伸びる不要な枝道を巡回する挙動は復活させません。
