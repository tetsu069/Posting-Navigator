# Posting Navigator v1.1.7 — 局所完結・蛇行巡回版

1町丁目を1本の巡回ルートとして生成するポスティングナビです。v1.1.7では、純粋な最短距離より「近くの区画を完全に終わらせてから次へ進む」現場の分かりやすさを優先します。

## v1.1.7 の主な変更

- 道路網を主な街路方向に合わせた約180〜250m単位のローカルブロックとして扱います。
- 現在のブロックに未処理道路が残っている間は、別ブロックへ移る動きを強く減点します。
- 完了済みブロックへ後から戻る動きを強く減点します。
- 格子状街区ではブロック列を交互方向に処理する蛇行（lawnmower）順を優先します。
- 幹道路にぶら下がる小さな袋小路・櫛の歯は、その幹道路を通っているタイミングで処理する従来ルールを維持・強化します。
- 町丁目外道路、公園内の不要園路、不要な幹線道路は巡回必須から除外するv1.1.6の方針を維持します。
- 全体のEuler化は1回のままなので、ブロックごとに別々のChinese Postmanを解く方式より不要な重複を増やしにくい構成です。

## ルートの優先順位

1. 今いる近接ブロックを完了する
2. その場の袋小路をまとめて処理する
3. 完了済みブロックへ戻らない
4. 格子状街区は上→下／右→左のように蛇行して潰す
5. その条件の中で重複距離・旋回を減らす
