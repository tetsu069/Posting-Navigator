# Posting Navigator v1.3.0 — 道路網羅性（completeness）強化版

v1.2.3をベースに、町丁目境界に沿う実道路が巡回対象から抜ける問題を修正しました。

## v1.3.0 の追加修正
- 境界をまたいで外へ続く道路のうち、町丁目内に55m以下だけ残る短い切れ端は配布必須から除外します。道路自体は移動用として保持するため、必要な接続は壊しません。
- 境界道路救済を5mから7.5mへ拡張。ただし境界と局所的に平行な区間だけを抽出するため、外向き枝道は救済しません。
- 1本のOSM wayが途中で曲がっていても、境界に沿う部分だけを局所判定して救済するため、長い境界道路の一部抜けを減らします。

## v1.3.0 の変更

- 町丁目内の道路は従来どおり厳密に対象化。
- 行政境界が道路端に置かれ、OSM道路中心線が数mだけ外側になる場合を救済。
- 救済対象は境界5m以内かつ境界とほぼ平行な生活道路系のみ。
- 境界から外向きに伸びる枝道は救済しない。
- 境界から離れた外側道路は巡回対象にしない。
- 救済した境界道路は `boundary_near=true` かつ配布対象として巡回する。
- v1.2.3 の無駄な即時往復除去・公園内不要路抑制などは維持。

## 狙い

地図上で「青い町丁目境界だけ表示され、実際の境界道路に巡回線がない」箇所を減らし、実在する境界道路を漏れなく配布対象に含めます。一方で、エリア外へ向かって伸びる不要な枝道を巡回する挙動は復活させません。


## v1.3.0 道路網羅性の修正
- エリア内の service / driveway / parking_aisle / road / track を、フィルタの取りこぼしで巡回対象から落とさない completeness pass を追加。
- access=private/no のタグだけを理由に道路Geometryを消さず、エリア内の実道路として保持する。
- 境界沿い道路は従来の「境界と平行な道路だけ救済」を維持し、外向き枝は救済しない。
- 公園内の徒歩園路・幹線道路は従来どおり原則巡回必須から除外。

## v1.3.0 未巡回道路ゼロ保証

- 町丁目内の `highway=*` は、幹線道路・cycleway・公園内の徒歩園路など明確に配布不要なものを除き、原則として巡回必須道路へ戻します。
- `service`, `driveway`, `parking_aisle`, `road`, `track`, 非公園内の `footway/path/pedestrian` も基準集合に含めます。
- 境界道路は10m以内で境界と平行な局所区間を3m単位で救済し、外向きの短い枝は従来どおり除外します。
- 生成後に required 道路集合と実際の巡回stepを照合し、未巡回道路が1区間でも残れば完成扱いにせずエラーにします。
