# Posting Navigator v1.1.9 — 階層型・全成分完走版

1町丁目を1本の巡回計画として生成するポスティングナビです。v1.1.9では、境界内の配布対象道路がOSM上で複数の連結成分に分かれていても、各成分を近い順に完全処理して最後まで巡回対象に残します。

## v1.1.9 の主な変更

- 配布対象道路が複数成分に分断されていても、1成分ずつ完全に巡回して次へ進みます。
- 成分間を実道路上で移動できる場合は、既存OSM道路だけを使って移動します。
- 実道路上で接続できない場合も、架空の直線は描きません。ルートを複数の連続パートに分け、次の成分の入口から再開します。
- 左の案内には「次の道路群へ移動」と表示し、道路外の偽ルートを作らずに全対象道路を最後まで巡回できます。
- 近い道路群から順に処理し、各成分内では行き止まりをその場で処理・ブロック完結を優先するv1.1.8の方針を維持します。
- 町丁目外の道路、公園内の不要園路は配布対象にしません。

## 表示上の意味

`manual_transfer_count` は、OSM道路ネットワーク上で接続できず、次の道路群へ徒歩移動して再開する回数です。この移動を道路外の直線として地図には描きません。
